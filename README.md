# HEX HUNT — Multiplayer

A deploy-ready real-time 2–6 player browser game.

## Run on your PC
1. Install Node.js.
2. Open a terminal in this folder.
3. Run: `npm install`
4. Run: `npm start`
5. Open http://localhost:3000

## Play with friends online
Deploy this folder to a Node.js host that supports a persistent WebSocket connection (for example Render, Railway, or Fly.io).
After deployment, share the generated HTTPS URL. Each player opens it, one creates a room, and the others join with the 6-character room code.

## Controls
WASD / arrow keys: move
Mouse: aim
Click: pulse attack
R: reload/reset page

The game uses stylized pulse/hex combat with no graphic effects.
